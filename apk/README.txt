สร้าง APK (repo แยกจากเว็บเซิร์ฟเวอร์ก็ได้)
1. สร้าง GitHub repo ใหม่
2. อัปโหลด zip เกมทั้งก้อน (เช่น Zhess-X-v14.zip) ไว้ที่ราก repo โดยไม่ต้องแตก
3. สร้างไฟล์ .github/workflows/build.yml โดยวางเนื้อหาจาก apk/build.yml
4. แก้บรรทัด SERVER_URL ในไฟล์นั้นเป็นลิงก์เซิร์ฟเวอร์ของคุณ (https://...onrender.com)
5. แท็บ Actions -> Build APK -> ดาวน์โหลด ZhessX-apk
อัปเดต: อัป zip ใหม่ (ชื่อเลขเวอร์ชันสูงกว่า) workflow เลือกไฟล์ล่าสุดเอง
ข้อควรระวัง: ตัวเกมในแอปกับเซิร์ฟเวอร์ต้องเป็นเวอร์ชันที่เข้ากัน ถ้าปรับกฎ/pop ให้ปล่อยแอปใหม่แล้วปรับ minimum ใน info.json
